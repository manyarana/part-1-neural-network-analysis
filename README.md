# Part 1 — Neural Network Fundamentals and Training Behavior Analysis

## Project Objective
The purpose of this project is to build and analyze a simple feed-forward neural network using a structured dataset.

This project demonstrates the complete workflow of training a neural network model, including:

- Dataset understanding
- Data preprocessing
- Neural network model creation
- Training and evaluation
- Hyperparameter experimentation
- Learning behavior analysis

---

# Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- TensorFlow / Keras

---

# Workflow

1. Load and understand the dataset
2. Handle missing values
3. Encode categorical variables
4. Scale numerical features
5. Split data into training and testing sets
6. Build a feed-forward neural network
7. Train and evaluate the model
8. Perform hyperparameter experiments
9. Analyze model behavior and performance

---

# Neural Network Architecture

The model contains:

- Input Layer
- Hidden Layer(s)
- Activation Functions
- Output Layer
- Adam Optimizer
- Appropriate Loss Function

---

# Evaluation Metrics

The following metrics were used:

- Accuracy
- Loss
- Confusion Matrix
- Precision
- Recall
- F1-score

---

# Hyperparameter Experiments

The following hyperparameters were tested:

- Number of hidden layers
- Number of neurons
- Activation function
- Learning rate
- Batch size
- Number of epochs
